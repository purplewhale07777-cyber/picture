# VIBO 定稿 Logo 交付包

本包按确认的定稿制作：蓝紫渐变同心圆环、实心中心圆点及 VIBO 字标。

- vector：彩色、黑色、白色；横版、竖版；SVG、EPS 与 Illustrator 兼容 AI 矢量文件。
- bitmap：透明底 PNG，含 300 dpi 元数据。
- preview：白底 JPG 预览图。
- documentation：Logo 使用规范与未签署的版权转让证明草案。

SVG 主稿保留标志和字标的命名分组。AI 文件为可编辑矢量 PDF 兼容格式。Pantone 为近似铜版纸参考，印刷前请核对实体色卡。版权证明仅为草案，须由实际权利人和受让方填写并签署后才生效。

竖版彩色 SVG 已按 8000 px 宽度渲染（相对 800 px 画板放大 10 倍），边缘保持清晰。
